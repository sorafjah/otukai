# おつかいチャレンジ

たのまれた ものを、たのまれた 数だけ あつめたり とどけたり しまったり する 3Dゲームです（iPad Safari 向け・単一HTML）。

- 公開ページ: https://sorafjah.github.io/otukai/
- ばめん: おつかい（スーパー）／はいたつ（いえに とどける）／たないれ（C-3 などの ばしょに おく）
  - ピッキングの コードは 残してあります。`CFG.scenes` に `'picking'` を足すと メニューに 出ます。
- むずかしさ: レベル1〜4（場面とは べつに えらぶ）
  - レベル1: 2しゅるい・メモ いつも 見える
  - レベル2: 3しゅるい・メモ いつも 見える
  - レベル3: 3しゅるい・メモは かくれる（ボタンで 見られる）・こまった ことが おきる
  - レベル4: 3しゅるい・メモは スタートでだけ 見られる・こまった ことが おきる
- こまった こと（レベル3・4）: うりきれ／にもつが たりない／おく ばしょが いっぱい。スタートの 人に「なにの ことか」と「こまって いる こと」を えらんで そうだん する。
- 検品: 1回目は「どれかが ちがいます」だけ。2回目から くわしく 出る。
- そうさ: ひだりしたの まるで あるく。たなの しなものを タップで かごに 入れる。かごの しなものを タップで へらす。はいたつ・たないれは もっている ものを えらんでから いえ・たなを タップ。
- かずの いいかた: しなものに あわせて「こ・ほん（ぽん・ぼん）・つう・ぶ」
- テスト用: `window.__game.api`（`tick`, `state`, `start`, `goTo`, `tap`, `screenOf`, `consult`, `trouble` など）
