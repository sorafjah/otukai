# おつかいチャレンジ

たのまれた ものを、たのまれた 数だけ あつめたり しまったり する 3Dゲームです（iPad Safari 向け・単一HTML）。

- 公開ページ: https://sorafjah.github.io/otukai/
- ばめん: おつかい（スーパー）／倉庫の しごと（ばんごうの たなから あつめる）／棚入れ（だいしゃの しなものを ばんごうの たなに しまう）
  - 配達のコードは残してあります。`CFG.scenes` に `'deliver'` を足すとメニューに出ます。
- むずかしさ: レベル1〜4（場面とは べつに えらぶ）
  - レベル1: 棚2台・正面から見る・メモ いつも見える
  - レベル2: 棚を1列に並べて歩く・にたもの（大・小）
  - レベル3: 3〜4しゅるい・色ちがいも混ざる・メモは15びょうで かくれる
  - レベル4: メモは スタートの「メモばん」に もどらないと見られない・メモは文字だけ・倉庫と棚入れは札が番号だけ（倉庫は品物が同じ箱）
- 設定: メモ（レベルに あわせる／いつも 見える／しばらくすると かくす／スタートに もどって 見る）、けんぴんの ヒント、見かた（レベルに あわせる／あるく／たなを 正面から 見る）
- 調整値は `index.html` 冒頭の `CFG` にまとめています。
