# おつかいチャレンジ

たのまれた ものを、たのまれた 数だけ あつめて とどける 3Dゲームです（iPad Safari 向け・単一HTML）。

- 公開ページ: https://sorafjah.github.io/otukai/
- ばめん: おつかい（スーパー）／倉庫の しごと（ばんごうの たなから あつめる）／配達（おうちごとに わけて とどける）
- むずかしさ: レベル1〜3（場面とは べつに えらぶ）
- 設定: メモ（レベルに あわせる／いつも 見える／かくす）、けんぴんの ヒント（1かいめは「ちがう」だけ／さいしょから くわしく）、見かた（あるく／たなを 正面から 見る）
- 調整値は `index.html` 冒頭の `CFG` にまとめています。
